# Legacy Codebase Analyzer

> An asynchronous code intelligence platform for understanding large JavaScript and TypeScript repositories through architecture visualization, dependency analysis and interactive code exploration.

## Overview

Legacy Codebase Analyzer helps developers understand unfamiliar repositories without manually navigating hundreds of files.

Upload a repository as a ZIP archive, and the platform builds a structured representation of the project by extracting metadata, analysing dependencies and generating interactive code flow visualizations.

The application is designed around an asynchronous job processing architecture so repository uploads remain responsive while analysis executes in the background.

↓

↓

↓

↓

---

## Deployment Notes

The application is deployed on Vercel for demonstration purposes.

Repository analysis depends on a dedicated BullMQ worker and Redis instance for asynchronous processing.

Since free serverless hosting does not support continuously running background workers, the public deployment focuses on demonstrating the user interface and application workflow.

The complete worker implementation, queue architecture and analysis pipeline are included in this repository.
